# M1 界面设计基准

视觉基准：`main-window-concept.png`。

- 背景：真实近白色；深色主题使用炭黑和低对比边界。
- 强调色：信号绿，仅用于运行、连接成功和启用开关；暂停使用琥珀色。
- 字体：Windows 中文 UI 字体栈；正文 13–14 px，标题 20–24 px。
- 容器：左侧固定导航、顶部状态条、中间开放式应用列表、右侧紧凑设置栏。
- 圆角：8–12 px；仅浮层和状态条使用轻阴影。
- 动效：120–180 ms，仅用于开关、悬停和状态变更；尊重 reduced motion。
- 图标：统一 1.8 px 线性图标，16–22 px。

首屏允许文案：应用代理、运行中、已暂停、常用应用、添加应用、代理地址、测试连接、定时暂停、局域网绕过、开机自启、退出后恢复直连、设置、诊断、关于。
